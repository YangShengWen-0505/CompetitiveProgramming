# CPE 與 UVA 解題紀錄

本專案整理以 C++ 撰寫的 CPE 與 UVA 題目解法，作為演算法練習與複習紀錄。

## 資料夾結構

| 資料夾 | 說明 |
| --- | --- |
| `CPE/1-star/` | 一星題目解法 |
| `CPE/2-star/` | 二星題目解法 |
| `CPE/4-star/` | 四星題目解法 |
| `CPE/CPE49/` | CPE 49 題題庫解法 |
| `CPE/CPE56/` | CPE 56 題庫練習，依場次分類 |

## 檔案與練習方式

每個 `.cpp` 檔案對應一道題目，檔名通常包含題號或題目名稱，方便查找。練習時請依題目要求編譯程式，並確認輸入與輸出格式符合線上評測平台的規定。

題目涵蓋字串處理、陣列與排序、搜尋與遞迴、數學與數論、圖論及動態規劃等基礎主題。
